# Third-party UI theme palettes

SHADED's workspace shell includes adapted colour palettes from [daylerees/colour-schemes](https://github.com/daylerees/colour-schemes):

- Carbonight
- Darkside
- Earthsong
- Legacy (Tron Legacy)
- Glowfish

The palettes are mapped onto SHADED UI roles (background, text, accent, status, warning, error, panel highlight) rather than copied as editor syntax rules. SHADED Neutral remains a project-local palette.

The theme picker also contains palette-value studies supplied directly by the user from visual references. Only the visible colour values were transferred; no source-site code or image assets are included:

- Electric Violet — `#D83F87 #2A1B3D #44318D #E98074 #A4B3B6`

- Cool & Collected — `#003135 #024950 #964734 #0FA4AF #AFDDE5`
